# site-safety-vlm

건설·산업 현장 이미지·영상에서 (1) PPE(안전모·안전조끼) 착용 상태와 (2) 불안전 행동을 판정하는
소형 VLM을 맥(Apple Silicon)에서 LoRA/QLoRA로 파인튜닝하고, 검증 · 규정 근거 · 리포트 단계를
**고정 파이프라인(A) / 싱글 에이전트(B) / 멀티 에이전트(C)** 로 구현해 같은 평가셋으로 비교하는 개인 프로젝트.

> 상태: 계획 단계. 결과 표는 실험이 끝난 뒤 채운다. 수치가 없는 항목은 아직 측정하지 않은 것이다.

## 흐름

데이터 준비 → zero-shot baseline → LoRA/QLoRA 학습 → 비교 · 어댑터 확정 → 영상 추론(PPE · 행동 후보)
→ 검증 · 규정 근거 · 리포트 (A / B / C) → 점검 리포트 → A/B/C 비교

전체 계획: `docs/PLAN.md`, 실험 기록: `docs/experiments.md`

## 폴더

| 경로 | 내용 |
| --- | --- |
| `configs/` | 모델 · 학습 · 구역 · 행동 규정 매핑 설정 |
| `src/sitesafe/` | 데이터 변환, VLM 추론 · 학습, 영상 집계, 규정 RAG, 에이전트(A/B/C), 트레이싱 |
| `eval/` | 평가 실행기, 라벨 점검 기록, 결과 |
| `scripts/` | 단계별 실행 스크립트 |
| `data/` | 원본 · 가공 데이터 (규정 발췌 `data/rules/` 외에는 git 제외) |
| `docker/langfuse/` | Langfuse 셀프호스팅 설정 (compose 파일은 공식 문서 최신판을 받아서 둔다) |

## 데이터와 라이선스

데이터 · 영상 원본은 레포에 올리지 않는다. 출처 · 라이선스 · 실제 장수는 `data_sources.md`에 기록한다.
일부 데이터는 비영리 라이선스(CC BY-NC)라 학습 · 포트폴리오 목적으로만 쓰고 가중치는 공개하지 않는다.

## 한계 (진행하면서 갱신)

- 행동 데이터는 한 공장에서 수집된 영상이라 다른 현장으로의 일반화를 주장하지 않는다.
- 합성 영상(SynthSite)은 파이프라인 동작 점검용이며 정확도 평가에 쓰지 않는다.
- 구역별 필수 장비(`configs/zones.yaml`)와 행동 클래스 → 규정 매핑(`configs/behavior_rules.yaml`)은 가정값이다.
