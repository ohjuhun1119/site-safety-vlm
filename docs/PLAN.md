# 계획 (사본)

원본은 노션 작업 페이지: https://app.notion.com/p/41a352da929e810d8160c2ee8b04cbe6
이 파일은 레포 안에서 보기 위한 요약이며, 내용이 다르면 노션이 최신이다.

## 목표

PPE(안전모 · 안전조끼) 착용 상태와 불안전 행동을 판정하는 소형 VLM을 LoRA/QLoRA로 파인튜닝하고,
검증 · 규정 근거 · 리포트 단계를 A 고정 파이프라인 / B 싱글 에이전트 / C 멀티 에이전트로 구현해
같은 평가셋으로 비교한다. 기간 약 6주.

## 흐름

1. 데이터 준비 (PPE: 이미지 · SteelBench 프레임 묶음 / 행동: mp4 클립) → 변환 · 중복 제거 · 출처 단위 분할
2. zero-shot baseline 측정 (프롬프트만 쓴 베이스 모델)
3. LoRA / QLoRA 학습 (PPE: 이미지 · 프레임 묶음, 행동: 영상 클립. 영상 입력 학습이 안 되면 프레임 묶음)
4. 같은 시험셋으로 비교 (베이스 vs LoRA vs QLoRA) → 최종 어댑터 확정
5. 영상 추론: PPE 프레임 샘플링 → 시간 집계, 행동 고정 길이 윈도우 → 이벤트 후보
6. 검증 · 규정 근거 · 리포트: A / B / C
7. 점검 리포트
8. A / B / C 비교

## 단계

| 단계 | 기간 | 내용 |
| --- | --- | --- |
| 0 | 1주차 전반 | 환경 · 데이터 확인, mlx-vlm 영상 입력 학습 스모크 테스트 |
| 1 | 1주차 후반 - 2주차 전반 | 데이터 파이프라인, 라벨 변환, 분할, 누수 점검 |
| 2 | 2주차 | 평가 실행기, zero-shot baseline, Langfuse |
| 3 | 3 - 4주차 | LoRA / QLoRA 학습 · 비교 |
| 4 | 5주차 - 6주차 전반 | A / B / C 구현과 비교 |
| 5 | 6주차 후반 | 마무리 (README, 재현 스크립트) |

## 원칙

- 실제로 한 방식 그대로 쓴다 (영상 입력 학습인지 프레임 묶음 학습인지 구분해서 기록).
- 수치가 나온 뒤에만 결과를 주장한다. 비교에서 이득이 없으면 그 결과도 그대로 기록한다.
- 데이터 원본은 올리지 않고 출처 · 라이선스는 `data_sources.md`에 기록한다.

## 변경 기록

- 2026-11-17: SteelBench 데이터가 공개되지 않아(HF 404) PPE 데이터는 CHVG + Roboflow safety 통합 분할로 대체한다.
  프레임 묶음 학습과 SteelBench 비교는 제외. 자세한 내용은 `docs/experiments.md` 6절. 노션에는 아직 반영 안 함.
